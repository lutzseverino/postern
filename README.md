<h1 align="center">Postern</h1>

Postern is a planned library for developers integrating code hosting platforms, providing facts about issues, pull requests, releases, and access.

[![Node.js 24 or 26](https://img.shields.io/badge/Node.js-24%20or%2026-339933?logo=nodedotjs)](https://nodejs.org/)

## Status

This repository currently contains the project scaffold and contribution
workflow. The library is not implemented yet, so there is no installation
command or working API example.
